# AlSura Mohamed Portfolio & Bootstrap Project

## Overview
This repository contains two main projects:

1. **Bootstrap Movie Showcase Project**
   - Built with Bootstrap 4.
   - Includes a navbar with bookmarks, jumbotron, movie cards, pill badges for showtimes, and deals section.

2. **Portfolio Website**
   - Built with HTML and CSS.
   - Features:
     - Fixed colorful navbar
     - Centered profile image with CSS filter and rounded edges
     - Styled table with borders, padding, and colored header
     - Text overlay on images
     - Two-column layout with custom colors
     - Paragraph hover effects
     - Image overlay fade effect
     - Autoplay muted looping video with text overlay
     - Footer with centered bold text

## How to Run
- Clone the repository.
- Open `index.html` in your browser.
- Ensure `sample.mp4` video file is placed in the project directory for autoplay video.
